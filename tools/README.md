# filetrack

Утилита, которая ищет и показывает, **куда и как** были перемещены или удалены файлы.
Только Python 3.8+, без зависимостей.

Перемещения определяются по содержимому (SHA-256), поэтому находятся даже файлы,
которые одновременно перенесли в другую папку и переименовали.

## Режимы

| Команда | Что делает |
|---|---|
| `filetrack.py snapshot [DIR]` | Запомнить состояние папки (сохраняется в `DIR/.filetrack.json`) |
| `filetrack.py diff [SNAPSHOT] [DIR\|SNAPSHOT2]` | Показать, что изменилось с момента снимка |
| `filetrack.py watch [DIR] [-i SEC]` | Следить за папкой в реальном времени |
| `filetrack.py git [PATH]` | Перемещения и удаления по истории git: коммит, автор, дата |
| `filetrack.py find NAME` | Проследить судьбу конкретного файла по истории git и подсказать, как его восстановить |

Типы событий: **перемещён** (другая папка), **переименован** (та же папка),
**удалён**, **скопирован**, **изменён**, **добавлен**.

## Примеры

```bash
python3 tools/filetrack.py snapshot ~/releases
# ... файлы двигают, удаляют ...
python3 tools/filetrack.py diff ~/releases/.filetrack.json
```

```
➜ ПЕРЕМЕЩЁН  a/one.txt
           → c/one.txt  (4 Б, имя не изменилось)
✎ ПЕРЕИМЕНОВАН  three.txt
           → THREE.txt  (6 Б)
✖ УДАЛЁН  c/five.txt  (5 Б)
```

```bash
python3 tools/filetrack.py git            # все перемещения/удаления в репозитории
python3 tools/filetrack.py find "*.jar"   # что происходило с jar-файлами
```

Полезные флаги: `--only deleted moved`, `--json`, `--ignore GLOB`, `diff -u` (обновить снимок после сравнения),
`git --copies` / `git --all`, `-C PATH` (другой репозиторий).
